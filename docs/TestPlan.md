# Тест-план Foodies — ручне функціональне тестування

**Для кого:** junior QA  
**Що тестуємо:** поведінка UI + запити до API (не зовнішній вигляд макета по пікселях)  
**Де дивитись мережу:** DevTools → Network, фільтр `Fetch/XHR`  

**Як фіксувати**
- `- [ ]` не пройдено · `- [x]` пройдено  
- У «Факт» — OK / баг + що побачив (статус запиту, текст на екрані)  
- Один баг — один issue: кроки, очікувано, факт, скрін  

**Обліковки**
- Юзер A — основний (логін/пароль команди)  
- Юзер B — другий акаунт (для follow / чужий рецепт)  
- Гість — incognito, без логіну  

**Брейкпоінти:** 375 / 768 / 1440. Критичні сценарії прогони хоча б на desktop і mobile.
